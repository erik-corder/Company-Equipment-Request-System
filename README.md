# Company_Equipment_Request

Employees can request laptops, monitors, keyboards, software licenses, or accessories. Managers approve/reject. IT/Admin prepares the item and marks it as issued.

## Technology Stack

- **Application type:** Web Application
- **Primary language:** Type Script
- **Frontend:** Nextjs
- **Backend:** .Net
- **Database:** MSSQL
- **Cloud provider:** Azure

## Getting Started

### Frontend (`frontend/`)
```bash
cd frontend
npm install
npm run dev
```
